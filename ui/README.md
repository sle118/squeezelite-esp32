# Web UI for Squeezelite-ESP32

Тонкая страница-оболочка отдаётся самим устройством (`GET /app`), а само приложение
загружается с GitHub Pages. Так интерфейс можно обновлять без перепрошивки: страница
живёт на адресе платы (значит все запросы к API идут same-origin), а `app.js`/`app.css`
подтягиваются по HTTPS.

## Разработка

```bash
pnpm install
pnpm dev        # http://localhost:5173 — API платы будет недоступен без прокси
pnpm build      # dist/: app.js, app.css, favicon.svg
```

Для работы с живой платой проще открыть `http://<ip-платы>/app` (нужна прошивка с
обработчиком `/app`) — оболочка загрузит опубликованный бандл.

## Публикация

`.github/workflows/ui.yml` собирает проект на каждый push, затрагивающий `ui/**`,
и публикует `dist/` в ветку `ui`. GitHub Pages отдаёт её по адресу
`https://<user>.github.io/squeezelite-esp32/`.

Адрес бандла хранится в NVS в параметре `ui_url` — его можно переопределить на
свою копию Pages.

## API, которое использует приложение

| Метод | Назначение |
|---|---|
| `GET /status.json` | состояние платы, сеть, Bluetooth, память |
| `GET /config.json` | все ключи NVS |
| `POST /config.json` | запись ключей: `{"config":{"key":{"type":33,"value":"..."}}}` |
| `GET /messages.json` | сообщения, в том числе прогресс OTA (`ota_pct`, `ota_dsc`) |
| `POST /reboot.json` | перезагрузка |
| `fwurl` в `POST /config.json` | установка прошивки по URL |

## Экраны

- **Статус** — плата, сеть, сервер, Bluetooth, память.
- **Плеер** — имя, сервер, таймаут; правится строка `autoexec1` целиком, без
  пересборки всех опций.
- **NVS** — список ключей с фильтром и подсказками.
- **Звук** — выход, буферы, логирование, имя Bluetooth-колонки.
- **Прошивка** — список релизов (по кнопке), установка с прогрессом.
